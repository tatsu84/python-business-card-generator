# 名刺作成プログラム

## 概要

Pythonを使用して、入力した会社名・役職・氏名・住所・電話番号などの情報から、名刺のPDFファイルを自動生成するプログラムです。

## 使用技術

* Python
* ReportLab
* Jupyter Notebook

## 主な機能

* 会社名、役職、氏名、郵便番号、住所、電話番号の入力
* 名刺サイズ（91mm × 55mm）のPDF生成
* 日本語フォントへの対応
* 色や文字の配置を調整した名刺デザイン
* 生成したPDFファイルの保存

## 工夫した点

* 名刺に記載する情報を入力するだけで、PDFを生成できるようにしました。
* 文字の大きさや配置、配色を調整し、見やすいデザインを目指しました。
* 日本語フォントを設定し、日本語の氏名や住所などを表示できるようにしました。
* フォントのファイルパスを変更しやすい形にすることで、特定のパソコン環境に依存しにくいコードを目指しました。

## サンプル

生成した名刺のサンプルは、[`sample/meishi_sample.pdf`](./sample/meishi_sample.pdf) から確認できます。

## 実行方法

### 1. 実行環境を準備する

PythonとJupyter Notebookを実行できる環境を用意します。

### 2. 必要なライブラリをインストールする

ターミナルなどで以下のコマンドを実行します。

```bash
pip install reportlab
```

### 3. 日本語フォントを準備する

IPAex明朝フォント（`ipaexm.ttf`）を用意し、Notebookファイルと同じフォルダに配置します。

フォントの入手先や利用条件については、IPAフォントの公式サイトを確認してください。

### 4. プログラムを実行する

Jupyter Notebookで `名刺作成ソフト.ipynb` を開き、セルを実行します。

画面の案内に従って名刺に記載する情報を入力すると、PDFファイルが生成されます。

### 5. 生成されたPDFを確認する

プログラムの実行結果に表示される保存先を確認し、生成されたPDFを開きます。
