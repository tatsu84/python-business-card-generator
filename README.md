# 名刺作成プログラム

## 概要

Pythonを使用して、入力した会社名・役職・氏名・住所・電話番号などの情報から、名刺のPDFファイルを自動生成するプログラムです。

## 使用技術

* Python
* ReportLab

## 主な機能

* 会社名、役職、氏名、郵便番号、住所、電話番号の入力
* 名刺サイズ（91mm × 55mm）のPDF生成
* 日本語フォントへの対応
* 色や文字の配置を調整した名刺デザイン
* 生成したPDFファイルの保存

## 工夫した点

* 名刺の情報を入力するだけでPDFを生成できるようにしました。
* 文字の大きさや配置、配色を調整し、見やすいデザインを目指しました。
* 日本語フォントを設定し、日本語の氏名や住所などを表示できるようにしました。

## サンプル

生成した名刺のサンプルは、リポジトリ内の `meishi_stylish.pdf` から確認できます。

## 実行方法

1. Pythonを実行できる環境を用意します。

2. ReportLabをインストールします。

   ```bash
   pip install reportlab
   ```

3. Jupyter Notebookでプログラムを開き、セルを実行します。

4. 画面の案内に従って名刺に記載する情報を入力します。

5. 生成されたPDFファイルを確認します。

## 制作について

Pythonを用いたプログラミング学習の一環として制作しました。コードの作成やエラーの修正を繰り返しながら、PDF生成の仕組みやレイアウトの調整について学びました。
